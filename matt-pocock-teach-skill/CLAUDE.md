# Matt Pocock Teach Skill

This project is a local installation target for Matt Pocock's `/teach` skill from `mattpocock/skills`.

## Installed Skill

- Source: `mattpocock/skills`
- Skill: `teach`
- Installer: `npx skills@latest add mattpocock/skills --skill teach --agent cursor --copy -y`

## Project Notes

- Keep project files inside this directory.
- Keep `AGENTS.md` and `CLAUDE.md` identical at this project level.
