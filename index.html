WebMCP Learning Project

Five progressive examples for understanding the Web Model Context Protocol — the W3C standard that lets websites expose structured tools to AI agents via navigator.modelContext.

Example 1
Basic Tool Registration
Your first WebMCP tool. Feature detection, registerTool(), inputSchema, and returning structured results.
imperative API beginner
Example 2
Counter with State
Tools that read and modify shared application state. Annotations like readOnlyHint and idempotentHint.
imperative API shared state
Example 3
Todo App
A complete CRUD app with six coordinated tools. Complex schemas with enums, filtering, and chained tool calls.
imperative API CRUD multiple tools
Example 4
Declarative Forms
Expose HTML forms as AI-callable tools using toolname, tooldescription, and toolautosubmit attributes. Zero JavaScript required for basic actions.
declarative API HTML attributes human-in-the-loop
Example 5
React Integration
Product catalog with search and cart. Custom useWebMCPTool hook, React lifecycle management, and component-scoped tools.
React imperative API hooks
