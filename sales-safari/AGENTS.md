# Sales Safari

A Sales Safari research project for discovering customer pain points, language, and buying triggers by systematically mining online communities, forums, and reviews.

## Project Structure

```
sales-safari/
  CLAUDE.md
  AGENTS.md
```

## Rules

- All project files stay inside this `sales-safari/` folder.
- `CLAUDE.md` and `AGENTS.md` must stay identical. When one is updated, update the other to match.
