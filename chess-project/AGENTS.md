# Chess Project

A 3D chess piece viewer built with Three.js.

## Structure

All project files live within the `chess-project/` directory.

- `index.html` — Main page with sidebar and 3D viewer
- `main.js` — Three.js scene, chess piece geometry builders, and interaction logic

## Running

Open `index.html` in a browser (requires a local server for ES module imports):

```
npx serve .
```
