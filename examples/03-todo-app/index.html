Key Concept: Multiple Coordinated Tools

Real applications need multiple tools that work together. This example registers six tools: add_todo, list_todos, toggle_todo, delete_todo, get_stats, and clear_completed. An AI agent can chain these tools to accomplish complex tasks like "add three high-priority items and then show me the stats."

Key Concept: Rich Input Schemas

The add_todo tool uses an inputSchema with an enum for priority levels and required fields. This schema tells AI agents exactly what parameters are valid, preventing errors before they happen. JSON Schema v7 is used — the same format as OpenAI function calling and standard MCP servers.
