Key Concept: What is a WebMCP Tool?

A WebMCP tool is a JavaScript function that you register with the browser via navigator.modelContext.registerTool(). Each tool has a name, a human-readable description, an inputSchema (JSON Schema) defining its parameters, and an execute function that runs when called. AI agents can discover and invoke these tools instead of scraping your page.

Key Concept: Feature Detection

Always check for WebMCP support before registering tools: if ('modelContext' in navigator) { ... }. WebMCP is currently available in Chrome 146+ behind a flag (chrome://flags → WebMCP). This project uses a polyfill so examples work in any browser.
