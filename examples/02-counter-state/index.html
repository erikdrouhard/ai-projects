Key Concept: Shared State Between UI and Tools

WebMCP tools operate on the same application state as the user interface. When an AI agent calls set_counter, the UI updates immediately. When a user clicks a button, the tool's get_counter reflects the new value. This shared context is one of WebMCP's core strengths — agents and users collaborate within the same page.

Registered WebMCP Tools

ToolDescriptionParameters
get_counter Returns the current counter value None
set_counter Sets the counter to a specific value value (number)
increment_counter Increases the counter by a given amount amount (number, default: 1)
decrement_counter Decreases the counter by a given amount amount (number, default: 1)

Key Concept: Tool Annotations

Tools can include annotations like readOnlyHint: true to signal they don't modify state, or idempotentHint: true to indicate they can be safely retried. These hints help agents make smarter decisions about which tools to call and when.
